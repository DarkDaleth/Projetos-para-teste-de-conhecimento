# Projetos e Estudos em Linguagem C

Repositório dedicado ao registro de projetos práticos, algoritmos e desafios técnicos desenvolvidos durante o curso de **Engenharia de Software (Estácio)** e estudos autônomos, com o objetivo de consolidar a lógica de programação e documentar minha evolução técnica para o mercado de trabalho.
